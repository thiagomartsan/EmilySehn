# Emily Sehn — Landing page V4

Landing page estática em HTML, CSS e JavaScript puro.

## Destaques desta versão
- hero editorial em duas cores, sem foto;
- identidade visual baseada no girassol;
- contatos de Instagram, WhatsApp e e-mail no topo;
- CTA global consistente: `Conversar pelo WhatsApp` no header, hero e CTA final;
- painel de atendimento presencial/online em duas cores;
- Maps e Waze apontando provisoriamente para Moinhos de Vento, Porto Alegre;
- FAQ acessível;
- botão `Voltar ao topo` no rodapé;
- animações leves com `transform`/`opacity` e suporte a `prefers-reduced-motion`;
- tracking preparado para WhatsApp, Instagram, e-mail, Maps e Waze via `dataLayer` quando GA4/GTM for conectado.
